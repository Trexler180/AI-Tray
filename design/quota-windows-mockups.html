Quota windows — timeline

An extra screen, not a replacement: the tabs keep doing what they do, and this answers "when does what reset, and am I burning it too fast?". A bar's length is a window's span (start → reset), the fill is the quota spent in it, and the dashed notch is now — fill ahead of the notch means you're outrunning the window. The range switcher decides which windows can be drawn honestly: Today puts 5-hour sessions on an hour axis where they're full-size bars, while Week and 2 weeks are the 7-day view you sketched, with sessions dropping to a density strip instead of unreadable slivers.

The full view. Switch ranges in the header — the row set changes with the range, because a 5-hour window is a bar at day scale and a tick at week scale.
IN THE TRAY (340 × 640, the real window)
Tray · Today. The day view survives the squeeze: 24 hours across 312 px is 13 px an hour, so a 5-hour window is still a 65 px bar. Finished sessions dimmed, the live one bright, next one dashed. The weekly row keeps the hourly burn plus a chip for its own total.
Tray · 2 weeks. The same screen at week scale: weekly bars read fine, sessions collapse to the density strip. This is the one that wants a wider window — the header link pops it out.
Where it's reached from. Nothing on Overview / Codex / Claude changes; a single row at the bottom summarises the next reset and opens the timeline. The sparkline is today's sessions, so the row is useful even if you never click it.
