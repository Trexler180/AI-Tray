01Overview: lead with what runs out first project

Today the Overview lists every window in a fixed order. You have to scan six bars and compare each fill edge to its pace line to find the one that matters. The proposal adds a "Runs out first" card with a forecast and the action that fixes it, gives each meter a word for its state, and labels the total as API value rather than spend.

Proposed
  • Runs out first: the tightest window across all accounts, its forecast, and the matching action (a banked reset here).
  • Forecast line only under meters that will run out before they reset. Calm meters stay one line.
  • State words (LOW, RUNS OUT) so colour isn't the only signal.
  • "$14.60 API value" with the same ⓘ as the value card, so it doesn't read as a bill.
  • Cards are real buttons with a focus ring (shown on Codex), and all five tab icons are SVGs.

02Meter states: three tiers and a "used up" state quick win

gauge() has one threshold: at 80% used the bar turns red and stays red to 100%. A window at 81% that will comfortably last looks the same as one about to run dry, and a used-up window is just an empty red track. The proposal splits that into amber (low), red (runs out before reset, or past 95%), and a striped "used up" state whose headline is when it comes back.

03Tray icon: show the number, not just the logo tooltip + menu live icon

The widget is off by default, so for most people the tray icon is the whole app until they click it. Today the icon never changes, its tooltip is the fixed string AI Usage (lib.rs:612), and the right-click menu has Refresh, Check for updates and Quit.

  • A dot means something needs you: a reset is available or about to expire, or a data source failed. Opening the panel clears it.
  • A setting picks what the ring follows: tightest limit (default), one chosen account, or the plain logo.

04Taskbar widget: hover for numbers, countdown when used up quick win

The widget shows shape but no numbers, and it has no tooltip, so the exact figure is always a click away. When a window is used up the cell becomes a full red bar, which says "stop" but not "until when".

06Settings: sections, thresholds, and a safe remove project confirm

Settings is one page of seven groups that runs well past the 640 px panel limit. The ✕ on a Claude folder removes it in one click, and removeDirectory ignores errors. The proposal adds a section switcher, moves diagnostics under Advanced, adds alert thresholds, and reuses the reset cards' inline confirm for removal.

07First run: surface the three things everyone wants quick win

The taskbar widget and limit alerts are off by default, and "Start with Windows" is at the bottom of Settings → About. A dismissible card on first launch offers all three in place.

09Compact mode for many accounts later

With three or more accounts the Overview scrolls. A compact mode shows one row per account (name, tightest window, reset time) so five accounts fit with room to spare. Clicking a row opens its tab.
